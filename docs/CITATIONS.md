# Citation corpus

41 sources (24 crossref-verified, 6 primary-read, 11 url-verified).
Machine-readable companion: [`CITATIONS.csl.json`](./CITATIONS.csl.json) (CSL-JSON).
This file is generated by [`scripts/generate_citations.py`](../scripts/generate_citations.py);
edit the JSON and regenerate. Only the preamble and the closing gaps ledger are hand-written.

Every entry here backs a specific constant or method in this repository. There's
no padding: if a source doesn't hold up a line of code, it isn't in the corpus.
The companion document [`VALIDATION.md`](./VALIDATION.md) measures whether the
methods actually work, and [`VERIFICATION.md`](./VERIFICATION.md) records what
happened when these claims were chased to their primary sources, including the
ones that did not survive.

## How to read this

### Verification status

This says how the *bibliographic record* was checked. It says nothing about whether
the finding is true, and nothing about whether this project applied it correctly.

| Status | Meaning |
|---|---|
| `primary-read` | The primary document was obtained and the specific table, row or passage this project relies on was read directly. The strongest status here, and the only one that licenses quoting a number as "from" the source. |
| `crossref-verified` | The DOI resolves in Crossref and the returned title, authors, year and venue were compared against what this repo claims. Any discrepancy is written into the caveat. Full text may never have been read. |
| `url-verified` | No DOI exists. An authoritative URL (standards body, grid operator, government agency) was fetched and the document identity confirmed from the page itself. |
| `unverified` | Neither a resolvable DOI nor a successfully fetched authoritative URL. Bibliographic details are inherited from secondary citation and may be wrong. |

A `crossref-verified` record can still carry a loud caveat. Verification confirms
the *citation*. Whether the *claim* holds is a separate question. Several entries are verified as references while
the number this project takes from them was never checked against the full text,
and those say so.

### Access level

`open-access` | `paywalled` | `public-domain` (government, national-lab or
intergovernmental output) | `standard-purchase` (must be bought from a standards
body).

### Evidence tier

Deliberately the same A-E scheme used by the companion project `carbon-lens`, so
the two corpora can be merged without re-tiering.

| Tier | Definition | How the product may use it |
|---|---|---|
| A | A grid operator's or standards body's own published methodology | May drive a headline number |
| B | Peer-reviewed method, independently replicated | May drive a headline number |
| C | Peer-reviewed but single-study, or a method published without validation | Must render as estimated, never as measured |
| D | Vendor white paper or blog with a stated method | Labeled, advisory only |
| E | Assumed, folk knowledge, or no source found | Must be visibly flagged in the output |

Where the code deviates from a cited value, the deviation and its reason live in
the record. An undeclared deviation is a bug; a declared one is a decision.
